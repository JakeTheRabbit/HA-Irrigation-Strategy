# Pre-lodgement audit checklist

Read the package as the MCA assessor will. Grade each finding:

| Grade | Meaning |
| --- | --- |
| BLOCKER | The MCA returns the application, or there is legal exposure. Do not lodge. |
| HIGH | Near-certain information request or inspection failure. Fix before lodging. |
| MEDIUM | Likely question or loss of credibility. Fix or answer in the cover letter. |
| LOW | Presentation. |

Give each finding an ID (`XX-001`), the file and page, the owner (us / customer / third party)
and the effort. Put the fix order in four groups: today, before lodging, with lodging, before
the inspection. A real audit of a container site found the issues below. Check each one.

## Blockers seen

- [ ] Supply agreement missing or a placeholder page. The MCA returns an application that does
      not show where the crop goes.
- [ ] A placeholder such as `[licence number]` left in any sent document or email body.
- [ ] A used custody record (manifest) that names an unlicensed site, or an instruction to
      "change" a used record. Correct by signed note only. Get legal advice if cannabis was there.

## High-risk issues seen

Site and land
- [ ] A second vehicle entrance not shown on the plans, or not closed by a locked gate.
- [ ] Landlord consent that covers a different act ("renew or extend") or no defined area.
- [ ] Registered owner never identified; consent only from a "landlord".
- [ ] Excluded parts of the lot (strip, cottage, other users) not explained: who uses them and how they get in.
- [ ] Nearby homes, childcare, shops or public places not addressed, with distances.
- [ ] Zoning, building consent and council position not confirmed in writing.
- [ ] Red outline used for the excluded area (convention: red = licensed area).

Security
- [ ] Perimeter described as existing when it is not continuous, or not 1.8 m, or not climb-resistant.
- [ ] No emergency exit from locked rooms or containers (inside release on every door).
- [ ] One camera per room where racks block the view.
- [ ] Siren, motion detectors and the secure store not shown on any plan.
- [ ] Alarm installer without a security technician licence; monitoring company name not verifiable.
- [ ] Battery or solar cameras in the plan.
- [ ] Glazed inner doors or a refrigeration-unit opening left as a weak point.
- [ ] Cover letter or email describes uninstalled security as in place.

Operations and records
- [ ] Odour plan says filters are fitted when the schedule says "to confirm".
- [ ] Electronic record system not named; no example records.
- [ ] Changes at an existing location (SOPs, records) not declared on the form.
- [ ] Research ticked with no quantities or justification.
- [ ] Cultivar list does not match the register, the last stocktake or Form D.
- [ ] Adopted SOP suite contradicts the site documents and no document says which controls.
- [ ] Staff numbers, witnesses and lone-worker check-in not given.
- [ ] Maximum dried stock on site not stated.

Supply and parties
- [ ] Buyer's activity (for example possession for manufacture) not proven, but a sworn form says "licensed manufacturer".
- [ ] Old supply agreements not ended or not disclosed.
- [ ] Consultant's authority and links to other licence holders not stated.

Timing and forms
- [ ] Plan assumes a new location renews separately from the licence.
- [ ] Statutory declaration sworn months before lodging (re-swear in the lodging week).
- [ ] A build-finish date in the cover letter that cannot be met.
- [ ] Documents stamped "draft"; wrong page size; untitled PDFs.
- [ ] No inspection evidence pack (record templates, registers, labelled as-built photos, NVR screenshot, alarm and fence certificates).

Outside the package
- [ ] Monthly supply returns or the stocktake late or missing.
- [ ] Website or social media: seed or clone sales, "grew before the scheme", "signed offtake" claims.
- [ ] Companies Office: director's full name, industry code.

## Output

Write the audit as an A4 HTML or PDF report: verdict banner ("DO NOT SEND YET" or "READY"),
counts by grade, fix order, a table of documents with verdicts, then the issue register.
