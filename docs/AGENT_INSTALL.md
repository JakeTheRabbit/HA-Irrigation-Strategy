# Installation for automation agents

Read [INSTALL.md](INSTALL.md) and the [feature matrix](FEATURE_MATRIX.md). The integration and controller must be installed together. Preserve existing room IDs and user mappings; keep engines off during configuration. Guided links require the source revision to be published. Do not claim live verification from mocked HA tests.

For source validation, use the commands in [TESTING.md](TESTING.md). The dashboard build packages all three delivery paths.
