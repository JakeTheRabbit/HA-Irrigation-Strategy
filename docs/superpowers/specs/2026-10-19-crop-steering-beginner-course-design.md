# Beginner course design

**Historical initial brief.** Later user instructions authorized media production and website publication. The current implementation is governed by [the academy delivery specification](2026-10-19-crop-steering-academy.md); this file preserves the earlier design scope.

The design and review pack is [Crop Steering from Zero](../../training/crop-steering-from-zero/README.md).

User brief: teach absolute beginners what crop steering means, including VWC and field capacity; plan a layered initial YouTube series using sound teaching methods; include the required equipment and setup.

The agreed working assumption is an adult beginner audience, plain English, safe one-zone-first equipment teaching and two routes: existing-system operator or new builder. Raspberry Pi and x86-64 host branches merge into a shared setup path. The requested deliverable is a reviewable course plan with practical materials, not an unrequested live deployment, paid media job or uploaded course.

Read the complete linked pack for the curriculum, functional bill of materials, five pilot scripts, exercises/answers, source evidence and production gates. Builder choices such as presenter, editor, recording schedule and locally available exact equipment models are explicitly left to production, subject to compatibility/commissioning checks before filming or energising hardware.

Acceptance: no assumed technical vocabulary; concepts before controls; equipment and commissioning included; observable practice and feedback; modern product workflows accurately distinguished; source evidence separated from teaching design; no universal crop target recipes; no claim that reference curves predict plant responses; clear remaining production work.
