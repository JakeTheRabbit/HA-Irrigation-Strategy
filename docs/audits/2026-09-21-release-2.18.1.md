## Run

- [ ] Dry run, kill switch OFF, one photoperiod: it decides and logs, no switch moves.
- [ ] Armed: a full grow-day, P0 → P1 → P2 → P3 → P0, including the counter reset at lights-on.
- [ ] Catch test: delivered ( ) L against counted ( ) L.

## Fault drills

- [ ] Home Assistant core restarted mid-day: nothing opens while entities read unavailable.
- [ ] Controller restarted with the kill switch ON: resumes, not stranded behind a disarm cycle.
- [ ] Host rebooted.
- [ ] Switch's device taken offline: no shot, a clear reason.
- [ ] Kill switch turned off mid-shot: valve closes at once, only the delivered part is counted.
- [ ] Valve made to fail its close (or its read-back faked): hardware hold latches and alerts.

## Rollback rehearsal

- [ ] Backup restored; room resumes with its counters and phase intact.
